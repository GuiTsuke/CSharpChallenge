# CSharpChallenge — desafios de C#

Repositório de exercícios de **C#**, identificado originalmente como **100 Days C# Challenge**.

## Objetivo

Registrar a prática de lógica, sintaxe e fundamentos da linguagem C# por meio de exercícios em aplicação de console.

## Tecnologia

- C#
- **.NET 8**
- Aplicação de console

## Estrutura

- `Exercises.cs` — exercícios
- `CSharpChallenge.csproj` — configuração do projeto
- `CSharpChallenge.sln` — solução

## Como executar

Pré-requisito: **.NET SDK 8**.

```bash
dotnet restore
dotnet run
```

O repositório tem finalidade de estudo. Os exercícios e a saída do programa podem variar conforme a implementação atual.

## No portfólio

Este é um repositório de **prática e aprendizado**, não uma aplicação finalizada de produção.
